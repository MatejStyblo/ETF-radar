# Autentické AI logy

Tento soubor je návod, nikoliv conversation export. Exportované soubory zde smí obsahovat pouze skutečné zprávy/logy použitého agenta. Žádné vymyšlené Claude Code/Hermes transcript ani zpětná rekonstrukce.

Postup a současné omezení viz `docs/AI_USAGE.md`. Export parent session musí použít její skutečné ID a secrets redaction. Skutečné delegation runtime logs lze uchovat jako dílčí záznam se zřetelně popsanou proveniencí; neoznačovat je jako kompletní parent chat.
